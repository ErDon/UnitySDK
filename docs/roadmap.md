# 迭代与验收计划

当前已进入实现阶段，具体代码与验证记录见 [工作计划](../WORK_PLAN.md)，当前交付边界见 [能力状态](status.md)。下表为完整目标，不代表所有项已经完成；契约测试、Unity 测试和真机验收分别记录。

| 迭代 | 交付 | 验收 |
|---|---|---|
| 0：设计基线 | 架构、模块边界、错误模型、升级策略 | 覆盖用户确认的要求 |
| 1：核心与示例 | 核心 UPM、Unity 桥接、Mock、登录示例与文档 | 空白 Unity 工程可安装并验证成功/失败/取消 |
| 2：配置与装配 | 模块勾选、依赖检查、预览、生产 Mock 阻断 | 关闭模块后无初始化，误调用返回明确错误，构建清单准确 |
| 3：微信基准 | 首批真实能力、服务端身份校验、版本矩阵 | 真机验证与 Mock 结果分开记录 |
| 4：其他平台 | 抖音、TikTok；Android/iOS 本轮只保留扩展接口 | 相同游戏示例验证接口语义及平台差异 |
| 5：支付闭环 | 订单、验签、通知、查单、业务发货示例 | 重复通知、超时、重启、幂等发货验证通过 |
| 6：多游戏复用 | 第二个独立游戏接入、稳定版本与升级演练 | 无 RS2 业务依赖，可锁版本及回退依赖 |

每次迭代提交代码、相关文档、示例、变更说明与验证记录。真实账号授权和支付测试需要具备相应环境，不以本地编译通过宣称真机通过。

当前验证基线：Unity 2022.3.14f1c1、微信本地 0.1.23 与官方固定提交 915d4bf 的 0.1.1 两条基线、抖音 TTSDK 6.9.7、TikTok 1.1.6 Release；公共服务端使用 Node 24.20.0。各平台来源及实际验证范围见兼容矩阵。Godot 暂不实现；以引擎无关协议保留扩展能力。
